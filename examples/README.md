# SV Printer Client Examples

Ready-to-use client libraries for integrating SV Printer into your application.

| Language | File | Dependencies |
|---|---|---|
| JavaScript / TypeScript | [`js/sv-printer-client.js`](./js/sv-printer-client.js) | None (uses native `fetch`) |
| Python | [`python/sv_printer_client.py`](./python/sv_printer_client.py) | `requests` |
| PHP | [`php/sv-printer-client.php`](./php/sv-printer-client.php) | `curl` extension |

See the [Integration Guide](../documentation/integration.md) ([Español](../documentation/integration_ES.md)) for full API documentation.
